Ever get tired of losing at Wordle??  Well,this little program will make it a lot harder for that to happen.

Download the `wordle_helper.zip` file, and decompress into any directory, then if you are a Mac, double click the `open_wordle.command`.  If not, just open `index.html`.  The algorithms and UI have all the data they need to run locally and boost your Wordle averages, and start beating that cheating Wordle bot.

I am purposefully not adding that many directions because I tried to make it as intuitive as possible, but you never know.

Let me know what you think!
